# FarPass — Безопасная передача секретов

> Внутренний сервис для одноразовой передачи паролей, токенов и файлов. Шифрование в браузере, ноль учётных записей, запуск в одну команду.

---

## Зачем

Пароли в Slack, почте и Jira **навсегда** остаются в логах, бэкапах и пересылках. FarPass — это простая альтернатива: вставил секрет → получил одноразовую ссылку → отправил коллеге. После открытия ссылка самоуничтожается.

Сервер **никогда** не видит открытый текст — шифрование PGP (AES-256) выполняется прямо в браузере.

---

## Возможности

| | |
|---|---|
| **End-to-End шифрование** | PGP/AES-256 в браузере, сервер хранит только шифротекст |
| **Одноразовые ссылки** | Секрет удаляется после первого открытия |
| **Автоудаление** | 1 час / 1 день / 1 неделя — на выбор |
| **Файлы** | Можно передать и текст, и файл |
| **Свой пароль** | Дополнительный слой защиты |
| **Без регистрации** | Открыл → вставил → отправил |
| **CLI** | Для автоматизации из терминала |

---

## Быстрый старт

```bash
git clone https://github.com/BarkovSA/farpass.git
cd farpass/deploy/docker-compose/insecure
docker compose up -d --build
```

Открывайте **http://localhost** — готово.

> Для продакшена — поставьте reverse proxy с TLS перед сервисом или используйте конфигурацию `with-nginx-proxy-and-letsencrypt`.

## Требования к серверу

| Ресурс | Минимум |
|--------|---------|
| CPU | 0.1 ядра |
| RAM | 128 МБ |
| Диск | 50 МБ |
| ОС | Любая с Docker |
| Порт | 80 (443 с TLS) |

Это легче одной вкладки Chrome. Живёт на любой имеющейся VM.
