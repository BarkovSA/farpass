# FarPass Logo Assets

This directory contains FarPass brand logo files in SVG format.

## Files

| File | Description |
|------|-------------|
| `farpass.svg` | Icon-only logo (shield + lock), 42×42 viewBox |
| `farpass-horizontal.svg` | Icon + "FarPass" text, horizontal layout |
| `farpass-vertical.svg` | Icon above "FarPass" text, vertical layout |
| `farpass-monochrome-horizontal.svg` | White silhouette, horizontal |
| `farpass-monochrome-vertical.svg` | White silhouette, vertical |

## Colors

- Primary gradient: `#FF6B00` → `#7B2FBE` (orange to purple)
- Accent: `#7B2FBE` (purple, used for "Pass" text part)

## Usage

The web application uses `website/public/farpass.svg` as its favicon and navbar icon.  
These files are brand assets for documentation, social media, and other materials.
